# チャネリくん 構文チェッカー

パターン①（21項目）とパターン②（18項目）の重複を統合した、ブラウザ内で動く試作版です。API・サーバー・アカウント登録は不要です。入力した文章は送信・保存されません。

## 使い方

`index.html` をブラウザで開き、回答を貼り付けて「構文をチェック」を押してください。自動判定できない意味・文脈・名前・期限などは下の手動チェック欄にまとめています。

## GitHub Pagesで公開

1. このフォルダーの `index.html`、`styles.css`、`script.js`、`README.md` をGitHubリポジトリのルートにアップロードします。
2. リポジトリの Settings → Pages で、Build and deployment の Source を **Deploy from a branch** にします。
3. Branch を `main`、フォルダーを `/ (root)` にして保存します。

公開URLを知っている人がアクセスできます。実際のクライアント情報を試す前に、公開範囲や端末の取り扱いを確認してください。

## 判定の限界と原票の差

- 文末、記号、見出し順などは文字列から確認できますが、内容の正しさや自然さは判断できません。
- パターン②の「結論は〜となりますに統一」と「標準量4〜5行×3〜4ブロック」は自動で候補を確認します。見出しや短い結論がある文章では、数字だけで読みやすさを確定できません。
- 回答期限はパターン①が「翌日23:59まで」、パターン②が「基本24時間以内」で異なります。実際の指定期限を優先してください。
- パターン②は句点「。」とカギかっこ（キーワードを除く）も避ける指定です。

上司の確認後に、実際の回答例をもとに判定条件を調整できます。

自動チェックの精度はまだ測定していません。実例で測る手順と記録欄は [accuracy-log.md](accuracy-log.md) と [accuracy-cases.csv](accuracy-cases.csv) に用意しています。
